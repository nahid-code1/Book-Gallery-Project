## Project Overview

Book Gallery is a responsive, frontend single-page web application built with React. It allows users to explore a collection of books, view detailed information, and organize their reading preferences.

Users can add books to their Readlist or Wishlist, manage their selected books, and sort their lists based on ratings or total pages. The application also uses browser Local Storage to preserve reading list data across page reloads.

The project focuses on React fundamentals, component-based architecture, state management, routing, and interactive user experiences.

## Core Features

- **Dynamic Book Rendering:** Loads and displays book information dynamically from a data source.
- **Book Details Page:** Displays individual book information on a dedicated route.
- **Readlist Management:** Add books to your Readlist and prevent duplicate entries.
- **Wishlist Management:** Save preferred books to your Wishlist with interactive toast notifications.
- **Context API:** Manages shared book data and reading lists across components.
- **Sorting Functionality:** Sort books by total pages or ratings.
- **Local Storage Integration:** Saves the Readlist in browser storage so selected books remain available after refreshing the page.
- **Tab Navigation:** Switch between Readlist and Wishlist using React Tabs.
- **Responsive Design:** Provides a user-friendly experience across desktop, tablet, and mobile devices.
- **Custom Error Page:** Displays a dedicated 404 page for invalid routes.

## How to Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/nahid-code1/Book-Gallery-Project.git
```

**2. Navigate to the project directory**

```bash
cd book-gallery
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```
